🔄 Retrain Machine-Learning Models

Retraining rebuilds the machine-learning models using the latest student data available in Student_performance_data.csv.

What happens during retraining?

1. The latest CSV dataset is loaded.
2. Required columns are validated.
3. StudentID is excluded from model features.
4. Actual GPA is excluded from GradeClass prediction.
5. Multiple classification models are trained.
6. Multiple GPA regression models are trained.
7. Cross-validation is performed.
8. Models are compared using evaluation metrics.
9. The best-performing models are saved.
⚠️ Important: Retraining uses the current contents of the CSV file. If you have recently added students, retraining allows the new records to become part of the training dataset.
