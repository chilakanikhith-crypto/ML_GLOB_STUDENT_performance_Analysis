🔄 Retrain Machine-Learning Models

Retraining rebuilds the machine-learning models using the latest student data available in Student_performance_data.csv.

What happens during retraining?

1. The current dataset is loaded.
2. Required columns and values are validated.
3. StudentID is excluded from model features.
4. Actual GPA is excluded from GradeClass classifier inputs.
5. Multiple classification models are trained.
6. Multiple GPA regression models are trained.
7. Cross-validation is performed when supported by the training code.
8. Models are compared using evaluation metrics.
9. The selected models and evaluation results are saved by the backend.
⚠️ Important: Retraining uses the dataset configured in your backend. If you have added student records to that CSV, the records may be included in training. Adding records alone does not guarantee improved accuracy. Check the backend training output to verify which file was loaded.

✅ Training Safeguards

🆔 StudentID is identifier-only
🚫 Actual GPA is excluded from GradeClass classifier features
📊 12 demographic and behavioral features are used
🔀 Cross-validation is used when configured in training
🌲 Multiple machine-learning algorithms can be compared
